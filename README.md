# Raiza Hotel 🏨

Aplicativo de reservas de hospedagem desenvolvido em C# com .NET MAUI, como atividade prática da Agenda 13 do curso Técnico em Desenvolvimento de Sistemas.

## 📌 Sobre o projeto

O Raiza Hotel é um aplicativo que simula o processo de reserva de hospedagem. A interface permite informar os dados do hóspede, selecionar o período da estadia e escolher o tipo de acomodação.

O projeto foi desenvolvido para praticar conceitos de interface gráfica, vinculação de dados e componentes visuais do .NET MAUI.

## 🚀 Funcionalidades

- Cadastro do nome do hóspede.
- Seleção da quantidade de hóspedes com o componente Stepper.
- Seleção das datas de entrada e saída com DatePicker.
- Escolha do tipo de acomodação com Picker.
- Atualização automática do resumo da reserva por meio de BindingContext.
- Validação dos dados antes da confirmação da reserva.
- Mensagem de confirmação da reserva.

## 🛠️ Tecnologias utilizadas

- C#
- .NET MAUI
- XAML
- Visual Studio

## 📚 Conceitos praticados

- BindingContext e data binding.
- Componentes Stepper, DatePicker e Picker.
- Construção de interfaces gráficas com XAML.
- Eventos e validação de dados em C#.

## ▶️ Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `MauiApp1-APPHOTEL.sln` no Visual Studio.
3. Aguarde a restauração dos pacotes NuGet.
4. Selecione o destino Windows Machine.
5. Execute o projeto pelo botão Iniciar.
